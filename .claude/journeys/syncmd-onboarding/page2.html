One content, many mount points

syncmd treats a group of equivalent files as one logical asset — then propagates the newest authored version to every member of the group.

  1. GroupAll the files that mean the same thing — CLAUDE.md, AGENTS.md, .cursorrules — form one equivalence class.
  2. Decide what's latestUncommitted edits rank as now; otherwise the last commit that touched the file wins.
  3. PropagateThe winner is written to every other member. A file that doesn't exist yet is simply created.
  4. Or report a conflictIf two members changed independently since the group last agreed, that's a real conflict — resolved by --strategy, losers always backed up.

It's a compiler, not a copier: it works out which member actually changed since the group last agreed, so a concurrent edit is reported — never silently clobbered.
