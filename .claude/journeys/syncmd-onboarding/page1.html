Claude Code reads CLAUDE.md. Copilot reads .github/copilot-instructions.md. Cursor, Gemini, Windsurf, Aider — each has its own. They almost always mean the same thing:

CLAUDE.mdAGENTS.md.cursorrules GEMINI.md.clinerulesWARP.md…

A teammate edits one of them. The rest silently go stale — and whoever opens the repo with a different tool gets outdated guidance.
