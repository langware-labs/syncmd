The project you're in is syncmd

It's already cloned and indexed here. Open a terminal in this project and try it: 

# preview only — compute the plan, write nothing
syncmd plan .

# sync every known group in the repo
syncmd sync .

# just the group one file belongs to
syncmd sync CLAUDE.md

# refuse to write when members diverged, and say so
syncmd sync . --strategy error

syncmd only works inside a git repo — the whole "which copy is latest" decision comes from history. It never initialises a repo or commits for you, and losers of a conflict are backed up as <member>.syncmd.bak.
