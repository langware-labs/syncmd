How it works

Four moves, all decided from git history plus your working tree:

  1. GroupFiles that mean the same thing — CLAUDE.md, AGENTS.md, .github/copilot-instructions.md — form one equivalence class.
  2. Decide what's latestYour uncommitted edit ranks as now; otherwise the last commit that touched each file wins.
  3. PropagateThe winner is written to every other member. A file that doesn't exist yet is simply created.
  4. Or report a conflictTwo members edited independently? That's a real conflict — resolved per --strategy, losers always backed up.

Preview first, write second: syncmd plan computes what would change and touches nothing; syncmd sync applies it.
