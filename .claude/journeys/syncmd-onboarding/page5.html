Plan, then sync

In the same terminal — preview what syncmd would do, then let it do it: 

# preview — computes the plan, writes nothing
syncmd plan .

# apply — CLAUDE.md is propagated to the group
syncmd sync .

plan should show AGENTS.md and .github/copilot-instructions.md as creation targets — your new CLAUDE.md is the only member, so it wins. (No syncmd binary? pip install syncmd first.)
